# AI Content n8n System

**Version:** v1.0 RC pre-n8n transfer baseline  
**Status:** GitHub-side completion hardening in review  
**Purpose:** modular n8n automation system for freelance AI content generation work.

This repository contains a database-backed n8n workflow system for handling AI-assisted client content jobs. It accepts a client brief, registers supporting assets, creates request analysis, generates a content plan, routes content-output tasks, stores generated outputs, QA-checks results, prepares a delivery pack, and keeps a supervisor agent informed.

This branch is intended to make the repo as complete as possible **before** anything is imported into Andy’s n8n server.

## Important import rule

Do **not** import raw workflow files one-by-one from GitHub URL for this system.

Use the clone-and-preflight path:

```bash
git clone https://github.com/andyhayes74-commits/Ai_Content_N8N_System.git
cd Ai_Content_N8N_System
bash scripts/validate_repo.sh
python scripts/static_workflow_audit.py
python scripts/pre_n8n_readiness_check.py
bash scripts/n8n_import_preflight.sh
```

The validation/preflight scripts regenerate the LLM and Drive workflows before checking/importing:

```bash
python scripts/build_llm_workflows.py
python scripts/build_drive_workflows.py
```

This avoids importing stale workflow JSON.

## Architecture

| Layer | Role |
|---|---|
| n8n | workflow execution and webhook/API layer |
| Postgres | durable job state and source of truth |
| Google Drive | client project workspace and file storage |
| OpenAI or LiteLLM | AI analysis, planning, generation, and QA |
| OpenClaw or Hermes | optional supervisor agent |
| Human approval | required before final delivery |

Postgres is the source of truth. AI models are not expected to remember job state.

```text

→ create_standard_folder_structure
→ scan_drive_assets
→ parse_and_summarise_documents

→ create_asset_index

→ generate_content_plan

→ route_output_tasks
→ generation workflows
→ qa_check_outputs
```

## Validation and preflight

Run from repo root:

```bash
bash scripts/validate_repo.sh
python scripts/static_workflow_audit.py
python scripts/pre_n8n_readiness_check.py
bash scripts/n8n_import_preflight.sh
```

Checks include workflow syntax, required coverage, webhook auth coverage, malformed expression scan, sensitive-action policy scan, obvious secret scan, LLM node presence, Drive node presence, approval gates, final delivery gate, and n8n CLI import shape.

This does **not** prove live credentials, but it should catch major GitHub-side build problems before n8n.

## Content safety rules

Generated content must not invent unsupported client facts, including dates, prices, claims, statistics, product features, locations, guarantees, testimonials, or endorsements.

Missing information must be flagged clearly. Risky, legal, medical, financial, or claim-heavy content should be marked for human review.
